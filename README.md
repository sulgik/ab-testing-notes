# 온라인 실험과 인과추론 — 대화로 배우는 노트

Kohavi·Tang·Xu의 *Trustworthy Online Controlled Experiments* 전 범위와 책 이후 주제(순차 검정, 이질적 효과, 밴딧, LLM 시대의 실험)를, "먼저 묻고 모르는 것만 배우는" 대화로 정리한 학습 노트입니다. 책의 요약이나 번역이 아니라 개념을 우리 말로 다시 설명한 것입니다.

**읽기:** GitHub Pages — `index.html`을 여세요. 모든 페이지는 A4 인쇄용으로 만들었습니다.

- `index.html` — 목차와 소개
- `lessons/` — 회차별 노트 (HTML)
- `style.css` — 화면·인쇄 공용 스타일
